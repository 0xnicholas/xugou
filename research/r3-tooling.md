# 研究：国内可用的建站与转化工具

- 执行日期：2026-11-04
- 研究对象：面向中国大陆访问者（含微信内置浏览器）的单页营销站
- 业务背景：AI Agent 定制开发（前台）+ 数据治理/本体（底座），客户为中国中小企业，团队人力有限，单一主 CTA = 预约 30 分钟场景诊断
- 方法：官方文档优先；价格与限制以官方页面为准；对无法确认的项目明确标注「未验证」
- 结论先行：**Astro 静态单页 + 腾讯云境内托管（Lighthouse 作备案资源，COS/CDN 可选）+ 金数据「预约」+ 微信客服/企微二维码 + 百度统计 + 自托管中文字体**。这是一套全部由境内服务组成、可在微信内完成「看到 → 预约 → 加企微 → 开会」闭环、且不依赖境外运行时的组合。

## 0. 选型维度与方法

每个候选按六个维度评估：

| 维度 | 要回答的问题 |
|---|---|
| 中国大陆可用性 | 境内是否有节点/主体；大陆访问是否稳定；微信内能否打开 |
| 备案 | 用境内托管时是否必须 ICP 备案；备案需要什么资源 |
| 境外依赖 | 运行时是否请求境外域名、境外账号、境外支付或境外日历 |
| 成本量级 | 免费额度、起步价、按量计费项 |
| 嵌入/集成方式 | 链接、二维码、iframe/script、API/webhook、SDK |
| 数据合规 | 个人信息是否出境；是否需要单独同意；数据存放在哪 |

**一个必须先讲清楚的前提：备案不是「买个域名」就自动完成。** 腾讯云文档明确：所有对中国境内提供服务的网站/APP 都必须先完成 ICP 备案，取得备案号后才能开通访问；未备案域名解析到腾讯云境内云服务器会被阻断 [S5]。阿里云同样说明未备案不得在境内从事非经营性互联网信息服务 [S8]。

更关键的是，**备案需要一项符合条件的境内云资源**。腾讯云列出的可备案资源包括：境内 CVM（包年包月、购买 3 个月及以上）、境内轻量应用服务器 Lighthouse（同样包月 3 个月及以上）、Serverless 资源包、负载均衡、备案授权码、云开发等 [S6]。**COS 本身不在这个清单里** [S6]。这意味着：即使静态文件放在 COS，也通常要先有一台满足条件的 Lighthouse/CVM 或购买 Serverless 备案资源包，才能完成备案。中国香港及境外云服务器无需备案，也不能用于备案 [S6]。

因此本研究把「备案资源」和「静态托管」分开考虑：Lighthouse 负责满足备案条件（也可直接用它跑 Nginx），COS/CDN 负责后续静态加速。

**方法说明（重要）**：本研究没有做全国多省拨测。文中「大陆可用性」的判断来自官方文档中的节点/合规说明；对境外服务的可达性只在本次执行环境做了单点 `curl` 探测，结果仅作参考，不能代表大陆整体网络。所有此类单点结果都标注为「本机实测」，不作为「被墙」的断言。

## 1. 静态站框架与托管

### 1.1 框架：Astro / Vite / Next.js

单页营销站的技术需求很窄：静态 HTML、少量交互、移动端优先、微信内打开、首屏快、SEO 可读。框架只影响构建，不影响大陆可达性；**Astro、Vite 都是构建期工具，产物是静态文件，运行时没有 Node 服务**。

| 候选 | 定位 | 大陆可用性 | 备案 | 境外依赖 | 成本 | 结论 |
|---|---|---|---|---|---|---|
| **Astro** | 静态优先的站点框架，默认输出静态 HTML，可按需加水合岛 | 构建期工具，无运行时地域问题 | 取决于托管，不取决于框架 | 无（可完全本地构建） | 免费、开源 | **推荐**：单页内容用 `.astro`/Markdown 写，构建出纯静态文件，微信内无框架运行时负担 [S14][S15] |
| **Vite + 原生 HTML/TS** | 构建工具，输出 `dist/` 静态产物 | 同上 | 同上 | 无 | 免费、开源 | **备选**：团队不熟 Astro 时最省心，单页甚至可以不构建 [S16] |
| **Next.js 静态导出** | React 框架，可 `output: 'export'` 出静态站 | 同上 | 同上 | 无（静态导出后） | 免费、开源 | **不推荐**：对单页营销站是过度设计；静态导出还有功能限制，收益低 [S17] |

判断：**Astro 的收益主要在内容组织、图片处理和「默认少 JS」**；如果最终只是一屏文案 + 一个预约表单，纯 HTML/Vite 也完全够用。不要把「框架」当成选型重点，托管与备案才是。

### 1.2 托管：境内静态托管 vs 境外 Pages

| 候选 | 大陆可用性 | 备案 | 境外依赖 | 成本量级 | 集成方式 | 结论 |
|---|---|---|---|---|---|---|
| **腾讯云 COS + CDN** | 境内多地域节点；可绑定自定义域名 | **需要 ICP**；且 COS 不在腾讯云备案资源清单，需另有合规云资源 [S6] | 无 | 新用户存储免费额度：个人 50GB、企业 1TB，有效期 6 个月；流量、请求、CDN 另计 [S10]；CDN 境内流量 **0.07 元/GB 起**，新用户有境内流量包 [S56] | 控制台开启静态网站，上传 `dist/`；绑定自定义域名 + CNAME；SPA 可配错误文档 [S1][S2] | **推荐作为正式静态托管**；注意 2024-01-01 后创建的桶用默认域名访问文件不支持预览，应绑定自定义域名 [S1] |
| **阿里云 OSS + CDN** | 境内多地域节点；可绑定自定义域名 | **需要 ICP**（境内托管）[S8] | 无 | 按实际使用量付费；存储/流量/请求分项 [S4] | 开启静态网站托管，上传文件，绑定自定义域名 [S3] | **等价备选**；与腾讯云二选一，优先选团队已有账号/发票主体的一家 |
| **腾讯云 Lighthouse + Nginx** | 境内节点；2C2G/3Mbps/200GB 套餐 | **可作备案资源**（包月≥3 个月）[S6] | 无 | **45 元/月，459 元/年**（2C2G、3Mbps、200GB/月）[S9] | 买服务器 → 备案 → Nginx 指向 `dist/`；也可只作备案资源，静态文件放 COS | **推荐给「还没有任何境内云资源」的团队**：一台机器同时解决备案 + 托管，最少概念 |
| **Cloudflare Pages** | 全球网络可访问；**中国大陆无境内节点**；China Network 是单独订阅、仅 Enterprise、由京东云运营、每个主域名都需 ICP [S11] | 不走 China Network 则不需要 ICP，但也没有境内加速 | Cloudflare 全球网络 | 静态托管有免费计划 [S12] | Git 集成/直传，全球 CDN | **不作为主站**：Cloudflare 官方明确说，经境外服务器回源的流量会因中国网络边界出现显著延迟和可靠性问题 [S11] |
| **Vercel** | **无中国大陆 Region**；区域列表最近的是 `hkg1` 香港 [S13] | 不适用（无境内节点） | Vercel 全球网络 | 有免费层；团队/企业另计 | Git 集成，全球 CDN | **不作为主站**：大陆访问要落到香港/东京/首尔，延迟与稳定性不可控 [S13] |
| **腾讯 EdgeOne Pages（观察项）** | 官方 Free Plan 宣传含中国访问；定价页同时给出免费/付费套餐的流量额度，Pages 文档未明确大陆加速的备案与可用性 [S18][S19] | 未验证 | 腾讯边缘网络 | 免费计划；付费套餐另计 | Git/模板/直传 | **暂不作为首选**：免费 + 中国访问很有吸引力，但「Pages 产品是否自动具备大陆节点、是否要求 ICP」官方文档没有说清，标注未验证 |

**关于「默认域名」的坑**：腾讯云 COS 文档提示，2024-01-01 后创建的存储桶，使用默认域名（含静态网站域名）访问文件不支持预览；建议开启静态网站后绑定自定义域名，源站类型选「静态网站源站」[S1]。营销站不要用 COS 默认域名直接投放。

**关于单页应用路由**：如果以后加前端路由，COS 静态网站需要把错误文档指向 `index.html` 才能避免刷新 404；腾讯云有专门的 SPA 实践文档 [S2]。当前单页站没有路由，这个问题可以先不处理。

### 1.3 备案的实际操作约束

| 事项 | 官方口径 | 对本案的影响 |
|---|---|---|
| 是否必须备案 | 所有对中国境内提供服务的网站/APP 都必须先 ICP 备案，取得备案号后才能开通访问 [S5] | 只要用境内托管 + 自有域名，就必须备案；微信内置浏览器不豁免 |
| 备案资源 | 境内 CVM/Lighthouse 包月≥3 个月、Serverless 资源包、负载均衡、备案授权码、云开发等；COS 不在清单 [S6] | 先买 Lighthouse（45 元/月）或 Serverless 备案包，再谈 COS |
| 香港/境外服务器 | 无需备案，也不能用于备案 [S6] | 不想备案只能放香港/境外，但大陆访问速度和微信内体验会变差 |
| 域名实名 | 域名需完成实名认证；一般 1–7 个工作日审核；信息同步工信部通常 1–3 个工作日 [S7] | 域名注册后不要马上提交备案，先等实名信息同步 |
| 备案费用 | 腾讯云 Serverless 备案说明称「备案本身不收取任何费用」，但需购买云函数资源包 [S6] | 备案本身不是大头，云资源才是 |
| 审核时长 | 各省管局规则不同；官方没有统一承诺 | 预留 2–4 周，不要卡在上线前才办 |

**建议**：如果团队还没有境内云资源，第一笔钱花在 Lighthouse（45 元/月）上，用它完成备案并直接跑 Nginx；等流量起来再迁到 COS + CDN。这样备案、托管、HTTPS 三件事一次解决，避免「先买 COS 却发现不能备案」的返工。

### 2.1 候选对比

|---|---|---|---|---|---|---|
| **金数据「预约」** | 境内 SaaS，官网/帮助中心均为境内主体 [S20] | SaaS 自带备案；落地页域名另需 ICP | 无 | 免费版每月 5 万条数据；付费版解锁预约；专业版 **599 元/年**、专业增强版 2,399 元/年、企业基础版 4,399 元/年 [S21][S22] | 预约链接/二维码；可嵌入微信公众号、APP、网站、小程序、微博、QQ [S20] | **推荐**：一个工具同时解决「选时段 + 限额 + 通知 + 微信内分享 + 线索表」 |
| **飞书「一对一预约」** | 境内 SaaS | SaaS 自带备案 | 无 | 版本/价格以飞书官网为准；预约功能本身未标价 | 分享外部链接；活动卡片支持「嵌入网页」，可选嵌入方式 [S23] | **备选**：团队已经在用飞书时很顺；但官方帮助文档注明「此功能内测中」，要求客户端 V6.6+ [S23] |
| **腾讯会议 + 表单/人工确认** | 境内 SaaS | SaaS 自带备案 | 无 | 版本/价格以官网为准 [S24] | 预约成功后人工/自动发送会议号或入会链接 | **只作会议载体**：腾讯会议负责开会，不负责收集「可预约时段」；不要把它当预约页 |
| **Calendly** | **未验证大陆可达性**；产品本身不面向中国本地化 | 不适用 | 定价页列出的集成为 Google、Microsoft Teams、Outlook、Office 365 日历，以及 Zoom/Google Meet/Microsoft Teams；美元计费 [S25] | Standard **$10/坐席/月（年付）**、Teams **$16/坐席/月（年付）**、Enterprise $15k/年起 [S25] | 嵌入链接/iframe | **否**：定价页未见企微/飞书/腾讯会议集成，日历与视频会议都依赖境外栈；大陆访问未验证 |

### 2.2 金数据「预约」的具体能力（推荐理由）

金数据官方预约页列出的能力，正好覆盖「预约 30 分钟场景诊断」：

- **日历预约模式**：按天/按时段开放，支持多项目、按日或按时段限量 [S20]。
- **取消/修改自动释放名额**：用户可自行取消或改期，名额回到池子 [S20]。
- **双向通知**：预约成功/取消/修改可通过微信、短信、邮件提醒用户；内部可通过企业微信群/钉钉群传达日程变化 [S20]。
- **多平台嵌入**：可嵌入微信公众号、APP、网站、小程序、微博、QQ [S20]。
- **确认码/核销码**：预约后生成唯一凭证，可用于到店/到会核销 [S20]。
- **数据导出/分析**：预约数据可查询、导出、打印，并生成可视化图表 [S20]。

对本案来说，最重要的是**它把「表单」和「预约」合并了**：用户在一个页面里选时段、填姓名/手机/公司/需求，提交后即进入线索池；不需要再维护一个 Calendly + 一个表单 + 一个日历三套系统。

### 2.3 飞书「一对一预约」的适用边界

飞书帮助文档描述得很完整：组织者创建预约活动，设置活动时长（15 分钟–12 小时）、可预约时间、缓冲时间、预约者信息（姓名/邮箱必填，可加自定义问题）；访客点外部链接选时间、填信息；系统发邮件给预约者，并自动在组织者日历上建日程；活动卡片支持「嵌入网页」[S23]。这对「团队已经在飞书里办公」的场景很合适。

但有两个硬约束：

1. **官方文档标注「此功能内测中」**，并要求客户端 V6.6 及以上 [S23]。内测意味着可用性、配额、界面都可能变，不适合作为唯一转化路径。
2. **它要求组织者和团队在飞书里**；如果客户/销售不用飞书，多一套账号体系就是额外摩擦。

因此：**飞书预约是「已有飞书团队」的加分项，不是本案的默认方案。**

### 2.4 腾讯会议的角色

腾讯会议是境内会议工具，适合作为「预约成功之后的会议载体」：金数据收集完时间与联系方式，人工确认后发送腾讯会议号/链接；或者用金数据的通知模板把会议链接带给用户。**官方产品页未见公开的「可预约时段」页面**——它的产品定位是开会，不是 scheduling [S24]。

### 2.5 成本与套餐注意

- 金数据免费版每月可收集 **50,000 条数据**，但预约属于付费能力；官方 FAQ 明确「付费升级后解锁预约」[S21]。
- 价格表（官方帮助中心「资费介绍」）显示：专业版 **599 元/年**、专业增强版 **2,399 元/年**、企业基础版 **4,399 元/年**、企业协作版 7,399 元/年、企业高级版 23,999 元/年 [S22]。
- **注意**：预约具体包含在哪个套餐，官方价格表没有逐项列出；「599 元/年起」是专业版标价，不代表预约一定包含在专业版。采购前要在套餐页确认，标注「未验证」。
- 企微群机器人推送（把新预约发到企业微信群）需要**企业基础版 4,399 元/年**及以上 [S26]。如果只是两三个人的小团队，用手机通知/每天看一次后台即可，不必为此升级。

## 3. 企业微信：加好友、群活码、客服

### 3.1 三种能力的分工

| 能力 | 官方接口/文档 | 能做什么 | 关键限制 | 适用位置 |
|---|---|---|---|---|
| **「联系我」二维码（加好友）** | `add_contact_way` [S27] | 为成员生成专属加好友二维码；支持单人/多人；可设 `skip_verify`、`state` 区分渠道；返回 `qr_code` 图片 URL | 调用应用需配置到「客户联系 可调用接口的应用」；成员需在企业微信激活、实名认证并配置客户联系功能；每个企业最多 50 万个「联系我」[S27] | 页面底部「加微信聊」、预约成功页、销售名片 |
| **「加入群聊」二维码（群活码）** | `add_join_way` [S28] | 生成客户群进群二维码；群满后**默认自动新建群**（`auto_create_room` 默认 1）；`chat_id_list` 初始最多 5 个群 | 与「联系我」共用 50 万额度；自建应用需配置到客户联系可调用应用；自动建群需要 `room_base_name`/`room_base_id` [S28] | 预约后拉群、直播/活动群、客户成功群 |
| **微信客服** | 微信客服概述 [S29]、`get_contact_way`/客服链接 [S30] | 在微信内/外网页接入客服；用户点击链接直接进会话；可生成二维码；支持 API 分配会话、收发消息 | 需在企业微信管理后台开通微信客服并配置接待人员；API 管理需单独开启 [S29] | 首屏「先咨询」、预约页「有问题？」、售后入口 |

### 3.2 嵌入方式

**「联系我」二维码**：API 返回 `qr_code` 字段，是一个图片 URL，直接 `<img src="...">` 即可；`state` 会出现在「获取客户详情」里，用来区分来自落地页、公众号、线下物料等渠道 [S27]。这比在后台手动下载一张固定二维码更有用：每个渠道一个 `state`，后续能算转化。

**群活码**：API 返回 `qr_code`，同样是图片 URL；`auto_create_room=1` 时群满自动新建，群名前缀由 `room_base_name` + 起始序号 `room_base_id` 控制 [S28]。`chat_id_list` 初始最多 5 个群；开启自动建群后，群满会继续新建，避免频繁换码 [S28]。

**微信客服**：官方明确「开发者可将该链接嵌入到 H5 页面中，用户点击链接即可向对应的微信客服账号发起咨询；也可根据该 url 自行生成二维码图片」[S30]。链接形如 `https://work.weixin.qq.com/kf/kfcbf8f8d07ac7215f?enc_scene=...`，还可以拼 `scene_param` 做渠道标记 [S30]。微信客服本身支持在微信内、外的网页接入 [S29]。

### 3.3 微信内置浏览器的 UX 判断

- **二维码在微信内通常需要长按识别**，多一步操作；**客服链接是一键点击**，路径更短。建议首屏/预约成功页用「微信客服」链接作为主咨询入口，二维码作为备用。
- 二维码图片域名是 `p.qpic.cn`（腾讯系），客服链接域名是 `work.weixin.qq.com`，都是腾讯系域名，不依赖境外服务 [S27][S30]。
- 群活码适合「已经预约/已付费」的人，不适合首屏陌生人：先加好友或先预约，再拉群，避免大量无效群。

### 3.4 成本

企业微信本身提供客户联系、微信客服、群聊等能力；基础使用没有按条计费的信息 [S31]。企业认证、会话存档、高级接口等是否收费、收费标准，官方产品页没有给出统一价格，**标注未验证**。对本项目，先按「0 元基础能力」估算，认证费用另计。

| 层 | 做法 | 依据/说明 |

### 4.4 自建表单的成本与适用条件

- 腾讯云 SCF 新用户前三个月（含开通当月）每月可 0 元试用个人高级版/标准版套餐包，之后按量计费 [S35]；具体计费项见 SCF 计费文档 [S36]。
- 自建需要：函数、API 网关、数据库（或表格存储）、验证码、日志、告警、备份。对两人团队，这些运维成本远高于 599 元/年的金数据。
- **只有在以下情况才自建**：已有 CRM 必须实时写入；数据不能放第三方 SaaS；需要复杂的线索评分/分配逻辑。

## 5. 统计

### 5.1 候选对比

| 候选 | 大陆可用性 | 备案 | 境外依赖 | 成本量级 | 集成方式 | 结论 |
|---|---|---|---|---|---|---|
| **百度统计** | 境内服务，脚本域名 `hm.baidu.com` [S43] | 站点需可访问；SaaS 自带备案 | 无 | 基础统计免费；实时访客最多 1000 条，提升上限需购买分析云 [S44] | 一段 JS 异步代码；支持事件/转化跟踪 [S43] | **推荐作为主统计** |
| **Umami（自建）** | 取决于部署地；部署在境内 Lighthouse 即境内 | 自建域名需 ICP | 无（自建后） | 软件开源免费；需要 Node 20.19+/PostgreSQL 12.14+，可 Docker 部署 [S45][S46] | 自托管，`script` 埋点；无 cookie、无跨站跟踪 [S45] | **可选补充**：不想把数据给百度、又愿意维护一台服务器时用 |
| **GA4** | **未验证大陆可达性**；采集/处理在 Google 侧 | 不适用 | Google 域名、Google 账号、境外数据处理 | 免费（有配额） | `gtag.js` / GTM | **不作为主统计**：数据出境合规 + 境外运行时依赖 |

### 5.2 百度统计的关键事实

- **代码**：异步代码从 `//hm.baidu.com/hm.js?<id>` 加载；官方推荐异步代码，称对打开速度基本无影响 [S43]。
- **能力**：支持 PV/UV、来源、事件、转化、实时访客等；高级 JS API 可跟踪按钮点击、表单提交等 [S43]。
- **上限**：基础统计实时访客最多最近 14 天、最多 1000 条明细；更高上限需购买「分析云」[S44]。
- **数据存放**：百度统计隐私政策明确「最终用户的个人信息均储存于中华人民共和国境内」；如涉及跨境会按法律法规执行 [S47]。
- **开发者义务**：百度统计要求开发者在产品显著位置告知用户集成了百度统计，并提供隐私政策链接、取得授权同意；还要提供访问/更正/删除/撤回同意等机制 [S47]。这不是「装上代码就完事」。

### 5.3 Umami 的关键事实

- 官方介绍：**不使用 cookie、不做跨站跟踪、不自动收集个人数据**；可以自托管，数据存在自己的基础设施里 [S45]。
- 安装要求：Node.js 20.19+（推荐 22 LTS）、PostgreSQL 12.14+；官方提供 Docker Compose（应用 + PostgreSQL）[S46]。
- 自建在境内 Lighthouse 上时，数据不出境；代价是要维护数据库、备份、升级、HTTPS。

### 5.4 GA4 与数据合规

- GA4 是 Google 的分析产品，采集脚本/请求指向 Google 域名，数据处理在 Google 侧 [S48]。
- 《个人信息保护法》第 13 条：处理个人信息需取得个人同意，或符合合同必需等法定情形 [S49]。
- 第 38 条：因业务需要确需向境外提供个人信息的，应满足安全评估、保护认证、标准合同等条件之一 [S49]。
- 第 39 条：向境外提供个人信息，应告知境外接收方名称/联系方式、处理目的/方式/种类、个人权利行使方式，并取得**单独同意** [S49]。
- 因此，GA4 不是「技术能不能访问」的问题，而是「有没有合法出境路径 + 有没有单独同意」的问题。对一个面向中国中小企业的营销页，**没有理由为此增加合规复杂度**。

**判断**：主统计用百度统计；如果团队对数据主权敏感，再加一个自建 Umami 做交叉验证。GA4 只在有海外主体/海外投放、且法务确认出境路径时使用。

## 6. 字体与资源

### 6.1 字体策略：系统字体优先，品牌字体自托管

| 方案 | 请求数/体积 | 大陆可用性 | 授权 | 结论 |
|---|---|---|---|---|
| **系统字体栈** | 0 请求 | 取决于用户设备，iOS/Android/Windows 都有中文字体 | 系统自带 | **正文首选** |
| **自托管 Noto Sans SC 子集** | 只打包用到的字形，通常几十 KB–几百 KB | 由自己的域名提供，境内可控 | SIL Open Font License（OFL），可商用/嵌入 [S50][S51] | **品牌标题/需要统一字形时用** |
| **Google Fonts 运行时** | 2 个字重的中文 CSS 就有 **202 个 `@font-face` 块、约 61 KB CSS**；抽样一个子集 woff2 约 3.7 KB（本机实测）[S52] | 本次执行环境 `fonts.googleapis.com` 可达、`fonts.google.com` 超时；未做大陆多省测量 | 各字体授权不同 | **不推荐运行时依赖**：多域名、多请求、境外 DNS/TLS，微信内弱网更明显 |
| **字节跳动静态资源公共库** | — | **官方页面标注「已下线」** [S53] | — | **不要用** |

授权成本：系统字体与 OFL 字体均为 0 元；商业中文字体（如某些品牌字体）按厂商报价，通常需要按年/按项目授权，本报告未涉及。

**推荐的字体栈**：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC",
  "Source Han Sans SC", sans-serif;
```

正文用系统字体，标题如果要统一品牌感，再用 `pyftsubset` 把 Noto Sans SC 裁成只含实际用字的 woff2，`font-display: swap`，放在自己的 COS/Lighthouse 上。这样既没有 Google Fonts 的运行时依赖，也不会让用户下载完整中文字体。

如果品牌需要更「中文」的字形，可评估 HarmonyOS Sans 或阿里巴巴普惠体；两者都需在官方页面核对商用授权条款，本报告未验证其完整授权文本 [S54][S55]。

### 6.2 其他资源

- **图标**：内联 SVG，不用 icon font，不用公共 CDN。
- **JS/CSS**：构建时打包进静态产物；不要依赖 `cdn.jsdelivr.net`、`unpkg` 等公共 CDN 的境内稳定性（本次未逐一验证，标注未验证）。
- **第三方脚本**：只保留金数据嵌入脚本和百度统计；都加 `defer`，并放在不影响首屏的位置。
- **图片**：WebP/AVIF，`srcset`，首屏图预加载，非首屏 `loading="lazy"`。
- **字体子集化**：只对标题字体做；正文系统字体不做子集化。
- **HTTPS**：全站 HTTPS；COS/OSS 自定义域名可配证书，Lighthouse 可用 Let's Encrypt。

**关于「境外资源」的结论**：不是所有境外资源都「被墙」，但营销站的运行时不应该把可用性押在境外域名上。Google Fonts、GA4、Calendly 这类服务，即使技术可达，也会带来额外的 DNS/TLS 延迟、隐私合规和账号依赖。**能自托管就自托管，能境内就境内。**

## 7. 推荐组合与取舍

### 7.1 推荐组合

```
用户（微信内/外）
   │
   ├─ 静态单页（Astro 构建 → 腾讯云 COS/CDN 或 Lighthouse Nginx）
   │     ├─ 首屏：主张 + 证明 + 单一 CTA「预约 30 分钟场景诊断」
   │     ├─ 预约区：金数据「预约」嵌入（选时段 + 姓名/手机/公司/需求）
   │     ├─ 咨询入口：微信客服链接（一键进会话）+ 企微「联系我」二维码（备用）
   │     └─ 统计：百度统计（PV/UV/CTA 点击/表单提交）
   │
   ├─ 提交预约 → 金数据记录 + 微信/短信/邮件通知
   │     └─ 人工/客服确认 → 发送腾讯会议号/链接
   │
   └─ 预约成功页 → 加企微 / 进群活码 → 后续跟进
```

| 层 | 选择 | 理由 | 成本量级 | 主要风险 |
|---|---|---|---|---|
| 框架 | **Astro 静态输出** | 单页内容好维护，默认少 JS，微信内快 [S14][S15] | 0 | 团队不熟 Astro 时学习成本；可退到 Vite/纯 HTML |
| 托管 | **腾讯云 COS + CDN**（正式）/ **Lighthouse + Nginx**（起步） | 境内节点、备案成熟、文档清晰 [S1][S9] | Lighthouse 45 元/月；COS 存储有 6 个月 50GB 免费额度，流量另计 [S9][S10] | 备案周期；COS 默认域名限制 |
| 备案 | **ICP 备案**，用 Lighthouse 作备案资源 | 境内托管合规必需；Lighthouse 同时可托管 [S5][S6] | 备案本身不收费；资源 45 元/月起 [S6][S9] | 各省管局规则/时长不同 |
| 预约 | **金数据「预约」** | 时段+限额+通知+微信分享+线索表一体 [S20] | 免费版 5 万条/月；付费版起步价 599 元/年（预约归属待确认）[S21][S22] | 预约具体套餐归属未验证；需采购前确认 |
| 企微 | **微信客服链接为主，联系我二维码为辅，群活码做后置** | 客服链接一键进会话；二维码可区分渠道；群活码自动建群 [S27][S28][S30] | 基础能力按 0 元估算；认证/高级接口未验证 [S31] | 二维码需长按；客服接待人力 |
| 表单 | **金数据**（与预约同一套） | 少一个供应商；嵌入/通知/导出完整 [S32][S33] | 含在预约套餐 | 免费版有广告/功能限制 |
| 统计 | **百度统计** | 境内、免费、支持事件/转化；数据存境内 [S43][S47] | 基础免费；更高上限买分析云 [S44] | 需隐私告知与同意；1000 条实时上限 |
| 会议 | **腾讯会议** | 境内、客户熟悉；预约后发链接 [S24] | 版本/价格以官网为准 | 免费/付费版本限制未验证 |
| 字体 | **系统字体栈 + 自托管 Noto Sans SC 子集** | 0 运行时境外依赖；OFL 可商用 [S50][S51] | 0（自托管流量极小） | 子集化流程需要一点工程 |

### 7.2 成本量级估算

按「Lighthouse 45 元/月 + 金数据专业版 599 元/年 + 域名约几十元/年 + 百度统计/企微免费」估算：

- 第一年现金成本约 **1,200–2,000 元**（不含人力、设计、投放）。
- 如果金数据预约必须上企业基础版（4,399 元/年）才能满足通知/自动化需求，则约 **5,000 元/年**。
- 如果改用 COS + CDN，Lighthouse 仍建议保留作为备案资源；COS 存储前 6 个月有个人 50GB / 企业 1TB 免费额度，流量按量计费；CDN 境内流量 0.07 元/GB 起，新用户有境内流量包 [S10][S56]。
- 相比 Calendly（$10/坐席/月，约 120 美元/坐席/年）[S25]，境内组合在「人民币开票 + 微信内体验 + 企微集成」上更合适；Calendly 只在团队已经在用 Google/Microsoft 日历时才考虑。

### 7.3 被否方案与原因

| 被否方案 | 原因 |
|---|---|
| **Calendly** | 日历/视频会议依赖 Google/Microsoft/Outlook 与 Zoom/Meet/Teams，美元计费；定价页未见企微/飞书/腾讯会议集成；大陆可达性未验证 [S25]。对本案是「多一套境外账号 + 多一层合规」，不是刚需 |
| **飞书「一对一预约」作为唯一方案** | 官方文档标注内测、要求 V6.6+；团队不在飞书时多一套账号体系 [S23]。可作为「已用飞书」的备选，不作为默认 |
| **腾讯会议当预约页** | 官方产品页未见公开的可预约时段/日历可用性功能；腾讯会议是会议载体 [S24]。必须配表单或人工 |
| **Cloudflare Pages 作为主站** | 大陆无境内节点；China Network 仅 Enterprise、需 ICP、由京东云运营；官方明确境外回源会有显著延迟/可靠性问题 [S11] |
| **Vercel 作为主站** | 无中国大陆 Region，最近香港；大陆访问延迟不可控 [S13] |
| **GA4 作为主统计** | 数据出境需满足 PIPL 第 38 条条件并取得单独同意 [S49]；对本案没有收益。仅在有海外主体/海外投放时考虑 |
| **Google Fonts 运行时** | 中文 CSS 就有 202 个 `@font-face` 块/约 61KB，多子集多请求；境外域名依赖；本机 `fonts.google.com` 超时 [S52]。自托管子集更稳 |
| **字节跳动静态资源公共库** | 官方页面已标注「已下线」[S53] |
| **腾讯问卷作为主表单** | 问卷能力强，但预约、线索分级、企微通知不如金数据直接 [S34]；可作为一次性调研工具 |
| **自建表单（v1）** | 需要函数、网关、数据库、验证码、日志、备份；两人团队维护成本高于 599 元/年的 SaaS [S35][S36][S41] |

### 7.4 落地时的硬约束（给实现票）

1. **先备案，再投放**：域名实名 → 买 Lighthouse（3 个月以上）→ ICP 备案 → 解析/上线 [S5][S6][S7]。
2. **一个主 CTA**：首屏只放「预约 30 分钟场景诊断」，不要同时放「加微信」「打电话」「下载白皮书」抢注意力。
3. **预约页闭环**：金数据预约表单提交后，成功页必须给「微信客服链接 + 企微二维码 + 腾讯会议说明」，不要让用户提交完不知道下一步。
4. **渠道标记**：金数据表单加隐藏字段 `channel`/`utm_source`；企微「联系我」用 `state`；客服链接用 `scene_param` [S27][S30]。
5. **统计事件**：百度统计至少埋 `cta_click`、`booking_submit`、`wecom_click` 三个事件；不然只知道 PV，不知道转化 [S43]。
6. **隐私合规**：表单页放隐私政策链接和同意勾选；说明收集姓名/手机/公司/需求的目的、保存期限、联系方式；百度统计的告知义务也要覆盖 [S47][S49]。
7. **微信内测试**：iOS/Android 微信各测一遍；重点看首屏、预约表单键盘遮挡、二维码长按识别、客服链接跳转。
8. **性能预算**：首屏 JS < 100KB（gzip）、字体只加载标题子集、图片 WebP/AVIF；不要在首屏加载 GA4/Google Fonts/大型图标库。

## 8. 未验证与待确认

以下项目在本次研究中**没有拿到可复现的官方结论**，落地前需复核：

1. **Calendly 在中国大陆的实际可达性/稳定性**：未做多省拨测；只确认了其产品依赖境外日历/会议栈、美元计费 [S25]。
2. **Google Fonts / GA4 在大陆多省的可达性**：本次只做了单点 `curl`；`fonts.googleapis.com` 与 `googletagmanager.com` 可达，`fonts.google.com`、`google-analytics.com/g/collect`、`developers.google.com` 超时。该结果受执行环境影响，不能代表全国 [S52][S48]。
3. **飞书「一对一预约」是否已 GA、哪些套餐可用**：官方帮助文档仍标注「内测中」，未找到 GA 公告 [S23]。
4. **金数据「预约」具体包含在哪个套餐**：官方价格表列出专业版 599 元/年起，但未逐项标明预约归属；采购前需在套餐页确认 [S22]。
5. **企业微信认证/高级接口的收费标准**：官方产品页未给统一价格 [S31]。
6. **腾讯会议各版本的人数/时长限制**：未在官方页面取到明确数字，以购买页为准 [S24]。
7. **EdgeOne Pages 的大陆节点与备案要求**：Free Plan 宣称含中国访问，Pages 文档未说明大陆加速是否需 ICP [S18][S19]。
8. **ICP 备案的具体时长**：各省管局不同，官方无统一承诺；本报告只建议预留 2–4 周。
9. **微信 JS-SDK 自定义分享卡片**：据常见接入流程需要公众号后台配置 JS 安全域名/业务域名（本次未查证到官方原文，**未验证**）；本案不依赖自定义分享卡片，未展开。若要做「分享到微信显示自定义标题/图」，需另开研究。
10. **公共 CDN（jsDelivr/unpkg）的大陆稳定性**：未逐一验证；建议构建时打包，不依赖运行时 CDN。
