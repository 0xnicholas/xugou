# 同类服务商定位与页面套路

> 研究票：#12「研究：同类服务商的定位与页面套路」
> 研究日期：2026-11-04
> 样本：20 个中国市场的官网／产品页／定价页，全部链接于当日抓取时返回 HTTP 200。
> 语境：本站要做的是「AI Agent 定制开发（前台）+ 数据治理／本体（底座）」的营销转化页，客户是中国中小企业，单一主 CTA 是「预约 30 分钟场景诊断」。

## 0. 给 spec 的 5 条结论

1. **定制服务价格普遍不透明，这既是行业惯例，也是最大空位。** 在可抓取到的页面文本里，20 个样本只有 3 个给出可直接做预算的数字价格：腾讯云 ADP（0／188／4880 元/月）、Dify（$590／$1590 每工作区每年）、趣果科技（轻量定制 4–8 周、5–15 万元起）。15 个非平台样本中，只有趣果 1 个公开项目价区间，其余 14 个只给「联系／演示／申请试用」。
2. **证明方式以「规模、品牌、资质」为主，缺少「过程 + 可复现结果」。** 平台厂商用模型和 benchmark，数据治理厂商用客户数、资质、标准，系统集成商用财报和中标新闻，RPA 厂商用 500 强案例和量化指标。零案例的新品牌无法复制这些证明，只能转向「诊断交付物 + 可复现 demo + 边界声明」。
3. **页面结构高度同质：Hero → 信任条 → 能力／产品矩阵 → 场景／行业 → 案例／数字 → 流程／资质 → 联系。** 价格、适用边界、诊断交付物、失败处理这几个位置几乎为空；差异不在「再加一个区块」，而在「把已有区块写出可核验的细节」。
4. **数据治理／本体与 Agent 两条叙事在样本中基本分开。** 数据治理厂商讲「底座／治理／图谱」，Agent 厂商讲「场景／数字员工」，系统集成商讲「集成／交付」。普元同时有「智能数据治理 + AI 应用开发」，中软国际发布了 allmeta Ontology V1.0，但都以大型企业产品线呈现；在可抓取到的首页叙事里，没有样本用「先理本体、再交付 Agent」作为中小企业的统一入口。这正是本站已定主线「底座让 Agent 答得准，Agent 让底座看得见」的空位。
5. **对中国中小企业，500 强 logo、无基线的大数字、平台／中台叙事、只演示不报价会失效。** 更可信的组合是：明确的适用／不适用边界、诊断交付物清单、固定范围与价格带、可复现 demo、失败处理，以及「谁来交付」。以上为基于页面模式的判断，未做 SME 访谈，建议在 #2／#8 用 3–5 个访谈验证。

## 1. 方法与样本

### 1.1 样本选择

按五类市场角色取样（在票面四类基础上，把垂直 Agent／RPA 单列），共 20 个对象：

- **平台厂商（5）**：阿里云百炼、百度智能云千帆、腾讯云 ADP、Dify、BetterYeah。
- **数据治理／本体（6）**：海致科技、普元信息、亿信华辰、袋鼠云、渊亭科技、明略科技。
- **系统集成／行业方案（4）**：软通动力、中软国际、东华软件、第四范式。
- **垂直 Agent／RPA（2）**：来也科技、实在智能。
- **精品 AI 公司／工作室（3）**：趣果科技、极思维智能、澜舟科技。

选择标准：中国市场、有公开官网／落地页、业务覆盖 AI Agent 定制、数据治理、知识图谱／本体、企业 AI 平台或系统集成中的至少一项；页面能看到定位、CTA、价格或证明中的至少两类信息。样本偏向「有成熟官网」的玩家，不代表全部市场，尤其是大量靠微信、渠道、招投标获客的服务商不在样本内。

### 1.2 取证方式

1. 直接抓取官网主页／产品页／定价页的正文，记录定位句、CTA、价格、案例和资质原文。
2. 对 JavaScript 渲染较重的页面，用原始 HTML 抽取导航、按钮、H2 区块标题，还原页面区块顺序。
3. 只把官网原文当作证据；360 搜索仅用于发现样本（例如找到趣果、极思维），结论不依赖搜索摘要。
4. 未做销售询价、未注册试用、未联系客户；所有价格均为页面公开标价，不代表实际成交价。

### 1.3 限制与未验证项

- **抓取限制**：海致、明略、软通的主页正文提取不完整，CTA 和部分证明可能被低估；BetterYeah 的「价格」页金额未渲染，只能确认存在价格页和试用积分。
- **排除对象**：星环科技、神州数码、汉得信息、智谱 AI 因 JS 渲染、521／500 或反爬，未能取得可靠首屏文本，未纳入表格；竹间智能域名无法解析。排除不代表对其评价。
- **未验证**：第 5 节关于「中小企业为什么不信」属于基于页面模式的推断，没有 SME 访谈或 A/B 数据；第 7 节的文案与报价建议是给 spec 的输入，不是已验证的市场结论。
- **价格口径**：趣果的「5–15 万元起」是其在 FAQ 中公开的报价区间，不是市场均价；腾讯 ADP、Dify 的价格是标准列表价，不含折扣、实施、模型调用和云资源。阿里、百度有按量单价或报价器，但需要先估算 Token 用量，不能直接换算定制项目预算，因此未计入「可直接做预算」的 3 个。

## 3. 四类玩家的打法差异

### 3.1 平台厂商：产品自助，价格透明，证明靠模型与规模

阿里云百炼、百度千帆、腾讯 ADP、Dify、BetterYeah 的主页都是「产品能力 + 免费试用／开通 + 价格或额度」（[百炼](https://www.aliyun.com/product/bailian)、[千帆](https://cloud.baidu.com/product/qianfan.html)、[ADP](https://cloud.tencent.com/product/adp)、[Dify](https://dify.ai/pricing)、[BetterYeah](https://www.betteryeah.com/)）。它们的共同假设是：买家有工程能力，能自己把平台用起来。

- **价格**：腾讯 ADP 最透明，直接把体验版、进阶版、企业标准版、私有化 License 分档；Dify 把 $590／$1590 的年费写在定价页；阿里用千万级、百度用百万级 Tokens 免费额度降低首次尝试成本，但不给项目预算。
- **证明**：模型矩阵、benchmark、GitHub stars、安全认证、全球客户；腾讯 ADP 是少数把具名客户和量化指标放在主页的。
- **CTA**：免费试用／立即开通／联系销售。对没有技术团队的中小企业，「试用」往往停在注册页，无法变成生产系统。

**对本站的启示**：不要做「平台试用」；把平台能力藏到交付背后，前台只卖「诊断 + 交付」。

### 3.2 数据治理／本体厂商：能力矩阵 + 资质 + 大客户，价格沉默

海致、普元、亿信、袋鼠云、渊亭、明略的主页是「产品矩阵 → 解决方案 → 客户数／资质 → 案例 → 联系」（[海致](https://www.haizhi.com/)、[普元](https://www.primeton.com/)、[亿信](https://www.esensoft.com/)、[袋鼠云](https://www.dtstack.com/)、[渊亭](https://www.utenet.com/)、[明略](https://www.mininglamp.com/)）。它们卖的是底座、治理、图谱、指标、数据资产，目标客户几乎都是大型企业。

- **定位词**：底座、基座、治理、图谱、认知智能、数据资产、多模态；抽象层级高，普通 SME 很难把「数据治理」映射到「我的哪个问题会被解决」。
- **证明**：客户数、项目数、参编标准、CMMI／DCMM、DAMA／Gartner、院士工作站、上市公司财报。这些是大型企业采购的信任货币，不是 SME 的购买理由。
- **价格**：全部不公开。定制项目按范围报价，官网只留「获取方案／联系架构师」。
- **案例**：普元用「大型制造／国有大行／万亿央企」匿名案例 + 650%、1100+、1800 万等指标；亿信用 13000+ 客户、25000+ 项目；海致用 26 省、院士工作站。具名案例少，匿名大数字多。

**对本站的启示**：数据治理／本体不能作为首屏主角，必须翻译成「让 Agent 答得准」的前置条件；否则会变成另一个「数据底座」，把 SME 吓走。

### 3.3 系统集成商：关系与资质驱动，新闻替代产品

软通、中软、东华、第四范式的主页更像「公司实力页」（[软通](https://www.isoftstone.com/)、[中软](https://www.chinasofti.com/)、[东华](https://www.dhcc.com.cn/)、[第四范式](https://www.4paradigm.com/)）：首屏常被新闻、财报、中标、客户 logo 占据，产品能力放在第二屏之后。

- **证明**：上市公司财报（软通 293.67 亿营收、东华 129 亿营收）、财富 500 强排名、中标新闻（雅砻江、温氏）、客户 logo（协和、华西、工行、建行）、交付纪录（15 天火神山）。
- **CTA**：联系我们／咨询／合作；没有自助入口。
- **价格**：不公开，按项目招投标。
- **对本站的意义**：SI 的信任构建方式对新品牌不可复制；不要模仿「公司实力页」，也不要用「服务过 500 强」这类无法验证的表述。

### 3.4 垂直 Agent／RPA 厂商：场景 + 500 强案例 + 量化指标

来也、实在的主页是「场景智能体 → 客户案例 → 证言 → 资质 → 下载／试用」（[来也](https://laiye.com/)、[实在](https://www.ai-indeed.com/)）。它们最接近「Agent 能干活」的叙事。

- **证明**：来也用「500 强企业的共同选择」、IDC APA 市场份额第一、连续六年 Gartner RPA；实在用吉利 300% 提效、裕同 20000 小时、海尔／周黑鸭证言。
- **价格**：不公开；用「下载体验／获取方案」收集线索。
- **弱点**：强在流程自动化，弱在数据质量与本体；案例几乎都是大企业，SME 难以判断自己是否适用。

**对本站的启示**：可以借「场景 + 量化结果」的叙事，但必须换成 SME 能复现的小样本，并补上「数据为什么不准」这一层。

### 3.5 精品 AI 公司／工作室：最接近本站，但仍有明显空位

趣果、极思维、澜舟是样本里最接近「中小型定制服务商」的形态（[趣果](https://www.quguonet.com/)、[极思维](https://www.jisiwei.com/)、[澜舟](https://www.langboat.com/)）。

- **趣果**：定位「企业 AI Agent 开发 · 大模型落地服务商」；首屏给「13 年、300+ 企业、2000+ 项目」；中段是产品 + 定制双能力；后段是 6 步流程 + 5 个 FAQ；CTA 是「免费咨询诊断」「加企业微信或电话直聊」。它是 20 个样本中唯一公开定制项目价区间的：「定制项目轻量场景 4–8 周、5–15 万元起」。
- **极思维**：定位「AI Agent 平台 + 算力聚合 + 具身智能 + 企业定制」；首屏给 500+ 企业、99.1% 可用性；中段是三产品 + 定制服务；后段是 4 步流程 + FAQ + 扫码。价格只给「按量计费／包年包月／企业定制」，没有数字。
- **澜舟**：定位「业界领先的认知智能公司」；主页以中国外运案例和 9 个行业解决方案为主；CTA 是商务合作邮箱，没有明确的诊断或试用入口。

**对本站的启示**：趣果的「流程 + FAQ + 价格区间 + 免费诊断」是最值得对标的骨架；但它仍然没有定义「诊断交付物」，也没有「不适合谁」的边界。这两点可以作为本站的差异化。

## 4. 页面结构与区块顺序

### 4.1 最常见的九段式

把 20 个主页按出现顺序拆开，最常见的骨架是：

1. **Hero**：一句定位 + 一句价值 + 一个 CTA。
2. **信任条**：客户 logo、服务客户数、项目数、资质或榜单。
3. **能力／产品矩阵**：3–7 个产品、能力或平台模块。
4. **场景／行业**：按行业、角色或痛点分 3–12 个场景。
5. **证明**：具名案例、量化指标、客户证言。
6. **方法／流程**：4–6 步交付流程，或「咨询 → PoC → 实施 → 运维」。
7. **商业信息**：价格、套餐、报价方式；多数服务商在这里放「联系销售」。
8. **FAQ／异议**：价格、周期、数据安全、私有化、能不能对接现有系统。
9. **底部 CTA**：表单、电话、二维码、企业微信。

代表性页面：

- [腾讯云 ADP](https://cloud.tencent.com/product/adp)：Hero → 四种搭建模式 → 企业底座能力 → 场景矩阵 → 套餐价格 → 6 个客户案例 → 购买指南／FAQ → 扫码进群。
- [普元](https://www.primeton.com/)：Hero → 三大产品体系 → 产品架构 → 场景方案 → 资质／资讯 → 3 个客户实践 → 标准参编 → 信创 → 服务生态 → CTA。
- [亿信华辰](https://www.esensoft.com/)：Hero／市场份额 → 产品矩阵 → 12 个解决方案 → 4 个数字 → 5 个行业方案 → 生态合作 → 权威认可 → 服务／联系 → 新闻。
- [趣果](https://www.quguonet.com/)：Hero → 客户 logo → 3 个产品 → 为什么选我们 → 定制开发 → 方法 → 6 步流程 → 5 个 FAQ → 联系。
- [极思维](https://www.jisiwei.com/)：Hero → 3 个数字 → 3 个产品 → 定制服务 → 关于 → 4 步流程 → 4 个数字 → 合作伙伴 → FAQ → CTA。

### 4.2 四类结构变体

| 类型 | 首屏 | 中段重心 | 价格位置 | 尾部 |
|---|---|---|---|---|
| 平台厂商 | 产品名 + 免费试用 | 能力矩阵、模型、场景 | 中段，公开套餐 | 案例 + FAQ + 开通 |
| 数据治理／本体 | 定位 + 客户数／资质 | 产品矩阵、解决方案、标准 | 缺失，只有「联系」 | 案例 + 资质 + 联系 |
| 系统集成 | 新闻／财报／客户 logo | 行业方案、交付能力 | 缺失 | 新闻 + 联系 |
| 精品／工作室 | 定位 + 数字 + 免费诊断 | 产品 + 定制 + 流程 | 后段，价格区间或「按量」 | FAQ + 微信／电话 |

### 4.3 首屏的三种写法

1. **名词型**：「企业级AI智能体平台」「AI原生数字基座」「认知决策智能基础软件」——先给品类，再解释。
2. **动词型**：「让智能体助力每个人」「让 AI 在企业里真正落地」「先思考清楚……下一代企业」——先给主张，再给产品。
3. **身份型**：「全球Agentic AI 第一股」「500 强企业的共同选择」「连续 5 年市场占有率领先」——先给地位，再给能力。

以上引语分别来自 [BetterYeah](https://www.betteryeah.com/)、[普元](https://www.primeton.com/)、[渊亭](https://www.utenet.com/)、[来也](https://laiye.com/)、[趣果](https://www.quguonet.com/)、[第四范式](https://www.4paradigm.com/)、[明略](https://www.mininglamp.com/)、[亿信](https://www.esensoft.com/)。

共同点是：**首屏很少回答「多少钱、多久、适合谁」**。这三件事被留到销售环节，而不是页面。

### 4.4 哪些位置是空的

> 表中「样本常见做法」均来自第 2 节对应对象的官网主页，具体 URL 见表格。

| 位置 | 样本常见做法 | 空位 | 对 SME 的价值 |
|---|---|---|---|
| 首屏下方 | 客户 logo、数字、资质 | 「适合谁／不适合谁」的自筛 | 降低「我不配」或「你太贵」的误判 |
| 价格区 | 「联系销售」「获取报价」 | 计价单位、价格带、包含／不包含、报价有效期 | 预算确定性，减少无效销售 |
| 案例区 | 500 强 logo、匿名行业案例、无基线大数字 | 小样本 demo、失败案例、边界与处理方式 | 相关性和可信度 |
| 方法区 | 「咨询 → PoC → 实施 → 运维」 | 诊断交付物清单、每步产出、谁来交付 | 把「咨询」变成可感知的商品 |
| 数据治理 | 底座、中台、治理、图谱 | 一张 SME 看得懂的本体图／数据准备清单 | 降低理解门槛，承接 Agent 叙事 |
| CTA | 表单、电话、扫码进群、下载 App | 微信内选时间、会前问卷、确认页 | 降低行动摩擦 |

## 5. 面向中小企业：哪些套路失效或不可信

> 本节是基于 20 个页面模式的推断，**未做 SME 访谈**；结论用于提出假设，不作为已验证事实。

| # | 套路 | 样本证据 | 为什么对 SME 失效／不可信 | 替代做法 |
|---|---|---|---|---|
| 1 | 大客户 logo／案例墙 | 腾讯 ADP、来也、实在、第四范式、东华 | 回答的是「能不能接大项目」，不是「会不会认真做我的 20 人公司」；还会暗示价格高、排期长 | 放 1–2 个与 SME 规模相近的匿名案例，注明行业、人数、上线周期、投入 |
| 2 | 无基线的大数字 | 实在「吉利 300% 提效」「裕同年省 20000 小时」；BetterYeah「75%／95%／22 倍」；普元「650%／1100+ 个应用／1800 万次调用」 | 没有基线、统计口径、时间窗口和样本量，SME 无法判断能否复现 | 写成「原来 3 人 × 2 天／周 → 现在 1 人 × 4 小时／周」，并说明怎么测 |
| 3 | 平台／中台／全栈／端到端 | 普元「AI原生数字基座」、袋鼠「多模态数据底座」、中软「全栈全场景」、腾讯「一体化全生命周期」 | SME 没有 IT 团队和数据团队，听起来像 6 个月、上百万的 capex 项目 | 说「一个场景、一个 Agent、2–4 周」，把平台藏到交付里 |
| 4 | 只给演示、不给价格 | 15 个非平台样本中 14 个不公开项目价 | 演示是销售筛选，不是购买依据；SME 更怕「聊完才知道买不起」 | 公开计价单位 + 价格带 + 报价规则；至少给「诊断后 48 小时书面报价」 |
| 5 | 免费试用／POC | 阿里、百度、腾讯、Dify、BetterYeah 都有免费额度或试用 | 试用验证的是平台，不是「我的数据能不能跑通」；SME 没有工程能力把试用变成生产 | 用「带你的数据跑 15 分钟」替代「注册试用」；POC 固定范围、固定价、固定退出条件 |
| 6 | 资质／榜单／标准 | 普元 CMMI5／DCMM4／38 项标准；亿信 DAMA／Gartner；来也 Gartner／IDC | 这些是大型企业采购的 checkbox；对 SME 读起来是成本、复杂度和距离感 | 用「交付清单」「评测方法」「数据安全做法」替代证书堆叠 |
| 7 | 融资／上市／第一股 | 明略「全球Agentic AI 第一股」；软通财报 | 不是买家证明；SME 更关心「第二个月谁接电话、出问题谁负责」 | 放「谁交付、怎么响应、出问题怎么处理」，而不是公司荣誉 |
| 8 | 私有化部署／24/7 支持 | 腾讯、百度、普元、极思维都提私有化；多家提 24/7 | SME 没有机房和运维；私有化意味着更贵、更慢；24/7 是标配不是差异 | 默认 SaaS／混合，明确数据存放、权限、导出和删除；把「响应时间」写成 SLA |
| 9 | 匿名行业案例 | 普元「大型制造／国有大行／万亿央企」；海致「金融、能源、制造」 | 无法核验，也无法判断是否与自己相似；匿名大客户反而强化「你只服务大企业」 | 匿名但具体：行业、人数、系统环境、原来怎么做、现在怎么做、失败点 |

**来源（按行）**：1 [腾讯 ADP](https://cloud.tencent.com/product/adp)、[来也](https://laiye.com/)、[实在](https://www.ai-indeed.com/)、[第四范式](https://www.4paradigm.com/)、[东华](https://www.dhcc.com.cn/)；2 [实在](https://www.ai-indeed.com/)、[BetterYeah](https://www.betteryeah.com/)、[普元](https://www.primeton.com/)；3 [普元](https://www.primeton.com/)、[袋鼠云](https://www.dtstack.com/)、[中软](https://www.chinasofti.com/)、[腾讯 ADP](https://cloud.tencent.com/product/adp)；4 见第 2 节表格；5 [阿里](https://www.aliyun.com/product/bailian)、[百度](https://cloud.baidu.com/product/qianfan.html)、[腾讯 ADP](https://cloud.tencent.com/product/adp)、[Dify](https://dify.ai/pricing)、[BetterYeah](https://www.betteryeah.com/)；6 [普元](https://www.primeton.com/)、[亿信](https://www.esensoft.com/)、[来也](https://laiye.com/)；7 [明略](https://www.mininglamp.com/)、[软通](https://www.isoftstone.com/)；8 [腾讯 ADP](https://cloud.tencent.com/product/adp)、[百度](https://cloud.baidu.com/product/qianfan.html)、[普元](https://www.primeton.com/)、[极思维](https://www.jisiwei.com/)；9 [普元](https://www.primeton.com/)、[海致](https://www.haizhi.com/)。

**一句话总结**：SME 不缺「AI 能做什么」的信息，缺的是「这件事在我这里值不值得做、要花多少钱、多久、做不成怎么办」。样本页面大多在回答第一个问题，很少回答后三个。

## 6. 5 个可借用的差异化空位

### 空位 1：把「诊断」做成有交付物的产品

**现状**：普元写「一对一诊断与定制方案」，趣果写「免费咨询诊断」，极思维写「预约咨询」，但都只有动作，没有说诊断结束会拿到什么。在可抓取到的主页文本里，没有一个把诊断交付物写成清单。

**空位**：30 分钟诊断 → 1 页场景图 + 数据准备清单 + 2–3 个候选 Agent + 报价范围 + 「不建议做」的理由；48 小时内书面交付。诊断本身可以免费，也可以低价可抵扣。

**页面用法**：主 CTA 下方直接列 4 个交付物；放一张脱敏的诊断纪要样例；文案写「不合适会直说」。

**来源**：[普元](https://www.primeton.com/)、[趣果](https://www.quguonet.com/)、[极思维](https://www.jisiwei.com/)。

### 空位 2：公开「价格带 + 范围边界」，而不是「联系销售」

**现状**：在可抓取到的页面文本里，20 个样本只有腾讯 ADP、Dify、趣果给出可直接做预算的数字价格；15 个非平台样本中只有趣果公开项目价区间（4–8 周、5–15 万元起）。其余 14 个只给「联系／演示／申请试用」。

**空位**：不公开折扣，但公开计价单位（诊断／试点／月度运维）、价格带、包含／不包含、报价有效期。对没有案例的新品牌，这是比 logo 更强的信任信号。

**页面用法**：价格区用 3 列卡片：诊断（免费／可抵扣）、试点（固定范围、2–4 周、X 万起）、上线后（按月／按 Agent）。每列写「适合谁、交付什么、不包含什么、多久」。具体数字由 #4 决定；可参考趣果的公开区间做锚，但不要照抄。

**来源**：[趣果](https://www.quguonet.com/)、[腾讯云 ADP](https://cloud.tencent.com/product/adp)、[Dify Pricing](https://dify.ai/pricing)。

### 空位 3：用「可复现的小样本」替代「500 强 logo」

**现状**：平台和 RPA 厂商的案例几乎都是大企业 + 大数字；腾讯 ADP 的迈瑞医疗、华润信托、碧桂园服务，来也的 500 强客户，实在的吉利、海尔、周黑鸭，都与 SME 的规模、数据条件、IT 能力差距很大。

**空位**：一个 3 分钟录屏 demo（真实输入 → Agent 输出 → 人工复核）、一个匿名化的小案例、一个失败案例及处理方式；标注「可复现／可现场重跑」。这比「服务过 500 强」更能让 SME 对号入座。

**页面用法**：案例区改成「看它怎么跑」；用 before／after 对照；提供「用你的数据跑 15 分钟」的微试用。

**来源**：[腾讯云 ADP 客户案例](https://cloud.tencent.com/product/adp)、[实在智能](https://www.ai-indeed.com/)、[BetterYeah](https://www.betteryeah.com/)。

### 空位 4：把「本体／数据治理」变成 SME 看得懂的一张图

**现状**：海致讲「图模融合」「产业级智能体」，普元讲「智能数据治理」「AI 原生数字基座」，中软发布 allmeta Ontology V1.0，但都是企业级术语；在可抓取到的主页文本里，没有样本给 SME 展示「你的业务本体长什么样、缺哪些字段会让 Agent 答错」。

**空位**：用客户熟悉的对象（客户、产品、订单、工单、合同、报价）画一张 10–15 个节点的本体草图；标出实体、关系、口径、缺失字段；把数据治理变成「让 Agent 答得准」的前置条件，而不是另一个平台。

**页面用法**：首屏下方放静态／可交互本体图；诊断交付物里包含「你的本体草图」；文案用「实体／关系／口径」而不是「数据底座」。

**来源**：[海致](https://www.haizhi.com/)、[普元](https://www.primeton.com/)、[中软国际](https://www.chinasofti.com/)（allmeta Ontology V1.0 发布）。

### 空位 5：微信内完成 30 分钟预约，而不是「扫码进群／填表等销售」

**现状**：腾讯 ADP 底部是「扫码加入交流群」，亿信是 400 电话 + 二维码，趣果是「加企业微信或电话直聊」，袋鼠是「填写表单，获取专属解决方案」；在可抓取到的主页文本里，没有样本提供「选时间 → 确认 → 会前问卷 → 日历邀请」的完整预约。

**空位**：微信内打开即可选时段、填 3 个问题、收到确认和诊断准备清单；不需要下载 App、不需要注册。对微信内打开为主的页面，这是最顺的转化路径。

**页面用法**：主 CTA 直接唤起预约组件；次 CTA 企业微信；底部 sticky CTA；确认页写「带一个真实场景来」。

**来源**：[腾讯云 ADP](https://cloud.tencent.com/product/adp)、[亿信华辰](https://www.esensoft.com/)、[趣果](https://www.quguonet.com/)、[袋鼠云](https://www.dtstack.com/)。

## 7. 对本站的直接建议

> 以下是把研究结论转成落地页输入的建议，最终取舍由 #2（定位）、#4（Offer／报价）、#5（证明）、#7（信息架构）、#8（文案）决定。

### 7.1 定位句：把「本体」翻译成「答得准」

**推荐主句**：

> **先理本体，再交付 Agent。**
> 面向中国中小企业的 AI Agent 定制与数据治理服务。

**备选**：

- 「让 Agent 答得准，让数据看得见。」（更抽象，适合作为品牌主张，不适合作为首屏唯一信息）
- 「不卖你一个平台，帮你把一个场景跑通。」（更锋利，适合作为副标题或 CTA 旁注）

**目标客户**：20–200 人、知识或流程密集、有数据但散落在 Excel／ERP／CRM／工单里、没有 AI 团队、希望 2–8 周看到第一个结果的中国中小企业。

**要避免的定位词**：AI 中台、数据底座、全栈、端到端、生态、赋能、闭环。这些词在样本中大量出现，但都是大型企业语言；对 SME 来说，它们等于「贵、慢、复杂」。

### 7.2 首屏文案（可直接给 #8 改写）

- **H1**：先理本体，再交付 Agent
- **副标题**：面向中国中小企业的 AI Agent 定制与数据治理服务。30 分钟场景诊断，先判断这件事值不值得做、要花多少钱、多久能上线。
- **主 CTA**：预约 30 分钟场景诊断
- **次 CTA**：加微信，先发一句你的场景
- **微文案**：诊断后 48 小时内给你：一页场景图 + 数据准备清单 + 书面报价范围。不合适会直说。
- **信任条**：不要放 500 强 logo；放「本周可预约时段」「平均 2–4 周上线第一个场景」「数据不出境／可混合部署」这类可验证的运营事实（数字需团队确认）。

> 以上为建议文案；「48 小时」「2–4 周」「价格带」需团队确认可执行后再上线，不能当作已验证承诺。

### 7.3 区块顺序（移动端／微信优先）

| 顺序 | 区块 | 目的 | 关键内容 |
|---|---|---|---|
| 1 | Hero | 3 秒说清「为谁、解决什么、下一步」 | H1 + 副标题 + 主 CTA + 微文案 |
| 2 | 你可能正卡在这 3 件事 | 让 SME 对号入座 | 数据散／答案不准；流程重复／人不够；买了平台／没人用 |
| 3 | 我们怎么解 | 把「本体 + Agent」讲成一条线 | 本体梳理（实体／关系／规则）→ Agent 编排（知识库／工具／流程）→ 上线运营（评测／监控／迭代） |
| 4 | 30 分钟诊断，你会拿到什么 | 把诊断变成商品 | 4 个交付物 + 诊断纪要样例 |
| 5 | 能做什么／不能做什么 | 自我筛选，建立信任 | 适合／不适合各 3 条；「不建议做」的三种情况 |
| 6 | 交付样例 | 替代案例墙 | 1–2 个匿名 demo／录屏；before／after；失败点 |
| 7 | 报价怎么算 | 预算确定性 | 诊断／试点／上线后三层；包含／不包含；报价有效期 |
| 8 | 为什么是我们 | 零案例下的证明 | 方法、交付清单、谁来交付、响应机制 |
| 9 | FAQ | 处理异议 | 多少钱、多久、数据安全、私有化、和买平台的区别、做不成怎么办 |
| 10 | 底部 CTA | 最后一次转化 | 微信二维码 + 电话 + 预约按钮 |

页面总长度控制在 7–9 屏；移动端一列，不要横向表格、不要 PDF 下载、不要 App 下载。

### 7.4 报价呈现：公开「规则」，不公开「折扣」

样本给三种可借用的做法：

- **[腾讯 ADP](https://cloud.tencent.com/product/adp) 的套餐透明**：0／188／4880 元/月，年付 9 折；让买家能自己估算。适合平台，不适合纯定制服务。
- **[Dify](https://dify.ai/pricing) 的「免费 Sandbox + 年费 + Enterprise 定制」三层**：免费层降低尝试门槛，年费层可预算，企业层保留议价。适合有产品化组件的服务商。
- **[趣果](https://www.quguonet.com/) 的「1–2 周标准产品；4–8 周、5–15 万元起定制」**：唯一公开定制项目区间的样本；用时间 + 价格双锚，降低「聊完才知道买不起」的恐惧。

**建议本站用三层**：

| 层级 | 公开什么 | 不公开什么 | 建议文案 |
|---|---|---|---|
| 诊断 | 免费／低价可抵扣；30 分钟；4 个交付物；48 小时书面纪要 | 具体诊断方法细节 | 「先诊断，再决定要不要做」 |
| 试点 | 固定范围、2–4 周、价格带「X 万起」、成功标准、退出条件 | 具体人天、折扣 | 「2–4 周跑通一个场景，不达标不进入下一阶段」 |
| 上线后 | 按月／按 Agent 数量／按调用量；SLA；包含的运维内容 | 大客户折扣 | 「上线后按月运维，随时可停」 |

**关键承诺**（建议，需团队确认可执行）：诊断后 48 小时内给书面范围与报价；报价 30 天有效；不捆绑年框；不把模型 API 费和云资源藏进「服务费」。

### 7.5 CTA 与表单：一个主 CTA，最多 5 个字段

- **主 CTA**：预约 30 分钟场景诊断（全站唯一主按钮）。
- **次 CTA**：加企业微信（二维码，备注「场景诊断」）。
- **表单字段**：称呼、公司／行业、想解决的场景、微信或电话、方便的时间。不要一上来要邮箱、预算、职位。
- **确认页**：选时间 → 3 个会前问题 → 日历邀请 → 「带一个真实场景来」。
- **不要做**：免费试用（我们是服务，不是平台）、下载白皮书（不是购买信号）、扫码进群（群不是诊断）。

### 7.6 零案例下的证明：五件可做的资产

| 资产 | 证明什么 | 放在哪 |
|---|---|---|
| 诊断模板（脱敏样例） | 我们知道怎么问问题 | 诊断区块 |
| 本体草图（用公开业务对象画） | 我们能把「数据」讲清楚 | 「我们怎么解」区块 |
| 3 分钟 demo（真实输入 → 输出 → 人工复核） | 我们真的能跑 | 交付样例区块 |
| 交付清单（每步产出、谁负责、多久） | 我们不是 PPT 公司 | 「为什么是我们」区块 |
| 边界声明（不适合的三种情况） | 我们不会什么都接 | 「能做什么／不能做什么」区块 |

**不要做**：编造客户 logo、用「某 500 强」当案例、放 stock photo 团队照、写「提效 300%」但没有基线。零案例时，诚实本身就是差异化。

### 7.7 话术清单

| 场景 | 建议说 | 不要说 |
|---|---|---|
| 首屏 | 「先判断值不值得做，再谈做不做」 | 「赋能企业智能化转型」 |
| 数据治理 | 「把客户、产品、订单、工单之间的关系和口径理清，Agent 才不会答错」 | 「打造企业级数据底座／中台」 |

| 证明 | 「这是我们自己跑的 demo，你可以带数据来重跑」 | 「服务过 500 强，提效 300%」 |

### 7.8 需要其他票决定的事项

- **#2 定位**：最终主句、目标行业优先级、是否聚焦「知识问答／流程自动化／经营分析」中的一个。
- **#4 Offer／报价**：诊断是否收费、试点价格带、上线后计费单位、是否承诺 48 小时报价。
- **#5 证明**：demo 用什么数据、是否拍录屏、诊断模板长什么样、是否招募 1–2 个种子客户换匿名案例。
- **#7 信息架构**：10 个区块是否合并、移动端 sticky CTA 的位置、表单是否嵌入。
- **#8 文案**：主句的最终措辞、FAQ 的 6 个问题、禁止词清单。
