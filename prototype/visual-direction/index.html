Wayfinder · 视觉方向 · 2026-11-06

同一套文案，三种视觉语言

要定的是：页面第一眼应该像什么。三个方向都遵守已定的首屏约束——不放 hero 大图、不放客户 logo、单一主 CTA；差别在气质、排版、图像语言与信息密度。

先读：这张原型要定什么，怎么评

票上的问题

页面应该长什么样？给出 2–3 个视觉方向（情绪板 + 首屏粗样），说明气质、适合谁、色彩 / 字体 / 图像 / 留白、移动端可读性、实现成本，最后给推荐。

已定，不在本票重开

首屏只放 eyebrow、H1、副标题、主 CTA、次 CTA、一行信任；无 hero 大图；两页结构；公开价格；零案例证明；单一 CTA。文案用 8 号票定稿的关键句，逐屏文案在 16 号票。

怎么评

1）先看 5 秒气质：像不像你会信任的供应商。2）再看手机框 844px 折叠线内：H1、副标题、CTA、信任条是否完整。3）看系统样张：报价 / 本体图 / 证明能不能撑住。4）记下想混搭的部分。

这不是最终视觉稿：颜色、字号、间距会在选定后精修；不包含 logo、摄影、插画、动效的最终制作。原型只用于讨论。想并排比较，可以开三个标签页：?variant=A / ?variant=B / ?variant=C。

我的建议

A 做主系统；B 的本体图只进 /method；C 的便签与直白语气只进证明 / 团队区。理由：A 最能把「先理知识结构」讲成判断力，成本最低、移动端最稳；B 的图纸语法在方法页是资产，在首屏会变成技术炫耀；C 的暖度适合拆「小团队靠不靠得住」，但不适合撑 12–15 万的报价。

A

Direction A

编辑部 · 判断书

把页面做成一份可读的判断书：宋体标题、细规则线、大量留白，先让人看到「我们有判断」，再看到「我们会 AI」。它假设访客对 AI 话术已经疲惫，愿意先读一段清楚的判断。

气质
可信 / 克制 / 有判断 / 纸面感
适合谁
对 AI 话术警惕、想先看判断依据的业务 / IT 负责人；老板扫一眼不觉得浮夸。
色彩
纸白 #FBF8F1 · 墨 #17140E · 赭石 #8E3B24 · 暖灰 #6C6558 · 细线 #DCD3C2
字体
标题：宋体（思源宋体 / Songti）700；正文：苹方 / 思源黑体 400；数字：Georgia / tabular。
图像
无摄影、无 3D；只用规则线、少量 SVG 线描和方形印章式标记。
留白
高。首屏留白 ≥45%；每屏只有一个视觉焦点。
移动端 / 微信
H1 37px 宋体 700；正文 13px；CTA 48px；信任条拆三行；不用横向滚动；标题加深，避免低端 Android 上细宋发灰。
实现成本
低。CSS 排版 + 1 个 SVG；中文宋体子集化 0.5–1 天；无插画 / 动效。
主要风险
宋体落不到思源时会被 SimSun 拉旧；整体偏「咨询公司」，需要价格表与样例把它拉回生意。

B

Direction B

结构图纸

把页面做成一张可读的工程图纸：网格、坐标、等宽标注和一张本体图，把「先理知识结构」变成看得见的方法。它假设访客有技术背景，想确认你不是套模板，而是真的懂知识层。

气质
精确 / 工程 / 可检查 / 有底牌
适合谁
有 IT / 数据背景的 AI 项目负责人；需要向老板解释「这件事有章法」的人。
色彩
工程纸 #EEF1ED · 墨 #0D1B18 · 松绿 #1F4D45 · 朱砂 #D4552F · 网格 #C7D2CC
字体
标题：苹方 / 思源黑体 650；标注：等宽（SF Mono / IBM Plex Mono / Consolas）；数字等宽。
图像
无摄影；本体图（对象 / 关系 / 规则 / 权限）是主要视觉资产；网格、坐标、图号、版本号是装饰语言。
留白
中。信息密度高，但用网格和层级控制；首屏背景网格很淡，不抢文字。
移动端 / 微信
网格降到 4 栏、坐标标注减半；H1 35px；本体图在方法页横向滑动并给出提示；首屏不放大图，避免 CTA 下沉；等宽标注 ≥12px。
实现成本
中。网格系统 + SVG 本体图 + 图注组件（约 2–3 天）；无摄影 / 3D；维护成本中等。
主要风险
容易变成技术炫耀，业务读者看不懂；必须把每个节点翻译成业务语言；蓝图纸感太强会显冷，需保留暖纸色。

C

Direction C

案头顾问 · 便签

把页面做成一张放在桌上的顾问便签：暖纸色、粗黑标题、便签卡和印章式标签，把「小团队、直说、负责人亲自交付」变成触感。它假设访客被大厂和外包伤过，先要确认对面是具体的人。

气质
直接 / 温暖 / 老练 / 不端着
适合谁
被大厂 / 外包伤过、怕被套路的业务负责人；老板在旁边看，觉得「这帮人说话实在」。
色彩
米纸 #F8F0E1 · 墨 #24201A · 柿 #C25B33 · 橄榄 #6F7D5C · 浅线 #E2D3BD
字体
标题：苹方 / 思源黑体 750–800，紧字距；正文 16px / 1.8；强调用粗笔触下划线（CSS），不用手写体；数字等宽。
图像
无 stock photo；CSS 便签、胶带、印章、箭头线描；如果要摄影，只拍真实工作台 1 张，不拍团队合影。
留白
中。卡片之间有呼吸，但不空；首屏像一张桌面，不像一张海报。
移动端 / 微信
便签卡在 CTA 下方，不挡按钮；H1 33px；CTA 48px 胶囊；信任条改成标签，允许换行；避免大面积低对比米色发灰，正文用深墨。
实现成本
低–中。卡片 / 印章 / 胶带 CSS 约 1 天；若加 1 张真实工作台照片或线描插画 +1–2 天；无 3D / 动效。
主要风险
过度「亲切」会削弱 12–15 万项目的专业感；圆角与便签容易像模板；必须克制用色和装饰，靠文案的直白撑住。
